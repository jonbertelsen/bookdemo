Layout + outlet + page

Click a destination: the shared layout stays, the outlet content changes.

Connect React to the browser

import { BrowserRouter } from 'react-router'

<BrowserRouter>
  <App />
</BrowserRouter>

BrowserRouter connects the app to the URL and browser history.

Wrap App once, in main.jsx. Keep the existing StrictMode.

Define routes with JSX

<Routes>
  <Route element={<LibraryLayout />}>
    <Route index element={<HomePage />} />
    <Route path="books" element={<BooksPage />} />
    <Route path="loans" element={<LoansPage />} />
  </Route>
</Routes>

path matches the URL. element is what renders.

The pathless parent adds a shared layout. Its children are nested routes.

The outlet renders the child

function LibraryLayout() {
  return (
    <>
      <Header />
      <Menu />
      <Outlet />
      <Footer />
    </>
  )
}

LibraryLayout
Shared structure around the pages.

Outlet
Where the matching child appears.

Index route
The default child at the parent URL.

Here, the index route displays HomePage at /.

Navigation with links

Link

<Link to="/books">
  Se bøgerne
</Link>

Choose a destination.

NavLink

<NavLink to="/books" end>
  Bøger
</NavLink>

Also marks the active destination.

Use links for in-app navigation without reloading the document.

With end, /books is active only at that path. Back and Forward still work.

Share data through the outlet

<Outlet context={{ books, loans, borrowBook }} />
↓
// Inside BooksPage
const { books, loans, borrowBook } = useOutletContext()

The layout owns the shared state. Pages read what they need.

Catalogue still receives ordinary props from BooksPage.

Dynamic segments identify a book

<Route path="books/:bookId" element={<BookDetailsPage />} />
/books/1
→
bookId = "1"
const { bookId } = useParams()
const book = books.find((book) => String(book.id) === bookId)

URL parameters are strings. A matching URL can still refer to a missing book.

Route prefixes group related URLs

<Route path="books">
  <Route index element={<BooksPage />} />
  <Route path="new" element={<AddBookPage />} />
  <Route path=":bookId" element={<BookDetailsPage />} />
</Route>

These routes match /books, /books/new, and /books/1.

This parent adds a URL prefix. With no element, it needs no extra outlet.

Navigate after a successful action

const navigate = useNavigate()

async function handleAdd(book) {
  const saved = await addBook(book)
  if (saved) navigate('/books')
  return saved
}

Save first. Navigate when saving succeeds.

If saving fails, stay on the form and display the error.

Handle an unknown destination

<Route path="*" element={<NotFoundPage />} />
/wrong-address
→
NotFoundPage

Add it inside the layout so the menu stays available.

Index = default child. Catch-all = unmatched URL.
A missing book is handled separately in BookDetailsPage.
